# Design records

Records of how parts of the compiler were designed, kept here because current code cites them for
its rationale. Each describes the code as it stood when written and is not kept current: when a
record disagrees with the reference docs or the interfaces, the latter win.

New design work happens on its GitHub issue. A record joins this directory only when it lands with
code that will keep citing it.

One file here is not a design record and is the exception to that rule: [decisions.md](decisions.md)
is a ledger of design decisions taken without the maintainer in the loop, each a pointer to the
comment on its issue that records it, kept so that the maintainer can review them after the fact.
It lands with no code, and it is kept current.
